# ФайлДроп (filedrop)

Простая передача файлов между компьютером и телефоном по интернету.

1. Загрузите файл(ы) — получите 6-символьный код, ссылку и QR.
2. На другом устройстве введите код или откройте ссылку.

Файлы удаляются через 24 часа. Лимит размера задаётся `MAX_BYTES` (по умолчанию 200 МБ).

## Запуск

```bash
npm install
npm start
```

Переменные: `PORT`, `MAX_BYTES`, `TTL_MS`, `UPLOAD_DIR`.
